# 1-3-3 알림

학습 카드의 **1-3-3에 담기**로 선택한 단어만 별도 풀에 저장한다. 스택이나 라이브러리를 삭제해도 이 풀과 완료 목록은 독립적으로 유지된다. 같은 일본어·한국어 조합은 중복 등록하지 않는다.

계정 → 1-3-3 알림에서 현재 풀 개수, 각 단어의 성공 횟수, 학습완료단어목록, 그만 보기 목록을 확인한다. 알림은 처음에 꺼져 있고 켤 때 iOS 알림·소리 권한을 요청한다. 기본 일정은 **매일 10:00~20:00, 60분 간격**이다. 간격은 30/60/90/120/180분, 시작·종료 시각, 주말 포함 여부를 바꿀 수 있다. 일일 상한은 없다. 풀이 비어도 추가를 안내하는 알림이 온다. 계정의 **5초 후 테스트 알림**으로 소리, 표시, 탭 진입을 확인할 수 있다.

알림을 탭하면 짧은 확인 화면이 열린다. 일본어를 보고 뜻을 확인한 뒤 **알았어요**를 누르면 성공 횟수가 하나 오른다. **다시 볼게요**는 횟수를 유지한다. 성공 3회가 되면 해당 단어는 학습완료단어목록으로 이동한다. **이 단어 그만 보기**는 완료로 처리하지 않고 알림 대상에서 제외한다. 한 번 진입하면 서로 다른 단어 두 개를 확인하고 화면이 자동으로 닫힌다. 남은 단어가 있으면 **더 학습하기**를 선택할 수 있다.

iOS는 다른 앱 화면을 강제로 전환하거나 앱을 종료할 수 없다. 알림을 사용자가 탭해야 확인 화면이 열리고, 두 단어 확인 후에는 그 화면만 닫힌다. 알림에는 기본 소리, 배지, 시간 민감 알림을 사용한다. 소리와 시간 민감 알림은 기기 설정에서 각각 허용해야 하며, 무음 모드·집중 모드·사용자 알림 설정에 따라 실제 표시 방식이 달라진다. 일반 일정은 반복 로컬 알림으로 예약한다. 평일 전용 30분 간격은 예약 개수 제한을 고려해 다음 60회를 미리 예약하고 앱이 활성화될 때 갱신한다.
