# 알림 기능 종료

2026-11-04 출시 준비 과정에서 알림 설정, 테스트 알림, 예약, 알림 진입, 시스템 알람 및 단축어 기능을 제거했다. 반복 확인은 ‘반복 학습’에서 수행한다.

새 권한은 요청하지 않는다. 기존 설치에서 업데이트했을 때 예약이 남지 않도록 앱 실행 시 로컬 알림과 배지를 정리한다. iOS 26 이상에서 이미 AlarmKit 권한이 허용되어 있는 경우에만 과거 앱 알람을 취소한다. 알람 정리를 위해 권한을 새로 요청하지 않는다.

예전 저장 파일의 단어와 학습 이력이 손실되지 않도록 과거 1-3-3 Codable 데이터 필드는 보존한다. 해당 데이터에서 알림이나 학습 동작이 실행되지는 않는다.

출시 현황은 [출시 점검표](release-checklist.md)를 참고한다.
