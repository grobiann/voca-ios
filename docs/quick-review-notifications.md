# 1-3-3 알림

학습 카드의 **1-3-3에 담기**로 선택한 단어만 별도 풀에 저장한다. 스택이나 라이브러리를 삭제해도 이 풀과 완료 목록은 독립적으로 유지된다. 같은 일본어·한국어 조합은 중복 등록하지 않는다.

계정 → 1-3-3 알림에서 현재 풀 개수, 각 단어의 성공 횟수, 학습완료단어목록, 그만 보기 목록을 확인한다. 알림은 처음에 꺼져 있고 켤 때 iOS 알림·소리 권한을 요청한다. 기본 일정은 **매일 10:00~20:00, 60분 간격**이다. 간격은 30/60/90/120/180분, 시작·종료 시각, 주말 포함 여부를 바꿀 수 있다. 일일 상한은 없다. 풀이 비어도 추가를 안내하는 알림이 온다. 계정의 **5초 후 테스트 알림**으로 소리, 표시, 탭 진입을 확인할 수 있다.

알림을 탭하면 짧은 확인 화면이 열린다. 일본어를 보고 뜻을 확인한 뒤 **알았어요**를 누르면 성공 횟수가 하나 오른다. **다시 볼게요**는 횟수를 유지한다. 성공 3회가 되면 해당 단어는 학습완료단어목록으로 이동한다. **이 단어 그만 보기**는 완료로 처리하지 않고 알림 대상에서 제외한다. 한 번 진입하면 서로 다른 단어 두 개를 확인한 뒤 완료 화면이 나온다. 중앙의 넓은 **터치하여 학습 화면으로** 영역을 터치하면 확인 화면이 닫히고 학습 탭으로 이동한다. 터치하지 않아도 30초 후 같은 동작을 한다. 남은 시간은 오른쪽 아래에 작게 표시한다. 남은 단어가 있으면 하단의 **조금 더 학습하기**를 선택할 수 있으며, 이때 자동 닫기 예약은 취소된다.

iOS는 다른 앱 화면을 강제로 전환하거나 앱을 종료할 수 없다. 알림을 사용자가 탭해야 확인 화면이 열리고, 완료 화면을 터치하거나 30초가 지나면 확인 화면을 닫고 학습 탭으로 돌아간다. 알림에는 기본 소리, 배지, 시간 민감 알림을 사용한다. 소리와 시간 민감 알림은 기기 설정에서 각각 허용해야 하며, 무음 모드·집중 모드·사용자 알림 설정에 따라 실제 표시 방식이 달라진다. 일반 일정은 반복 로컬 알림으로 예약한다. 평일 전용 30분 간격은 예약 개수 제한을 고려해 다음 60회를 미리 예약하고 앱이 활성화될 때 갱신한다.

## 시스템 알람과 바로 열기 (iOS 26 이상)

계정 → 1-3-3 알림 → 바로 학습하기에서 **시스템 알람 사용**을 허용하고, **10~20시 · 30분 간격 적용**을 누른 뒤 상단의 **1-3-3 알림 켜기**를 켠다. 종료시간은 포함하지 않아 10:00~19:30에 하루 20회 울린다. 위쪽의 간격·시간·주말 설정은 시스템 알람에도 적용된다. iOS 17~25에서는 기존 일반 알림을 사용한다.

알람은 AlarmKit의 매주 반복 일정으로 예약하므로 앱을 매일 열어 다시 예약할 필요가 없다. 풀에 단어가 없어도 울린다. 시스템 알람 모드에서는 일반 정기 알림을 취소해 중복을 방지한다. **5초 후 시스템 알람 테스트**는 정기 알림 켜짐 여부와 관계없이 한 번만 울린다. 알람의 **1-3-3 시작**을 누르면 울리는 알람을 멈추고 복습 화면을 연다. 잠금 상태에서는 잠금 해제가 필요할 수 있으며, 사용자의 터치 없이 다른 앱 위로 학습 화면을 강제로 띄우지 않는다.

단축어 앱의 voca-ios 동작 **1-3-3 학습 시작**도 같은 화면을 직접 연다. 이 동작을 홈 화면이나 원하는 자동화에 연결할 수 있다. 단축어 자체에 시간별 자동화를 여러 개 만들 필요 없이, 정기적인 강한 알림은 앱의 시스템 알람 모드를 사용한다.

검증 시 App Intent 런타임은 서명된 앱이 필요하다. 시뮬레이터 테스트도 `CODE_SIGNING_ALLOWED=YES CODE_SIGN_IDENTITY=- DEVELOPMENT_TEAM=`으로 로컬 서명한다. 서명을 생략하면 알람이 앱만 열고 Intent 메타데이터를 찾지 못할 수 있다.
