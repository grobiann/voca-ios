# 1-3-3 알림

학습 카드의 **1-3-3에 담기**로 선택한 단어만 별도 풀에 저장한다. 스택이나 라이브러리를 삭제해도 이 풀과 완료 목록은 독립적으로 유지된다. 같은 일본어·한국어 조합은 중복 등록하지 않는다.

계정 → 1-3-3 알림에서 **현재 풀**을 누르면 단어별 성공 횟수, 학습완료단어목록, 그만 보기 목록을 확인할 수 있다. 알림은 처음에 꺼져 있고 켤 때 iOS 알림 권한을 요청한다. 기본 일정은 **매일 10:00~20:00, 60분 간격**이다. 간격은 30/60/90/120/180분, 시작·종료 시각, 주말 포함 여부를 바꿀 수 있다. 일일 상한은 없다. 종료 시각 자체는 알림 시각에 포함하지 않는다. 풀이 비어도 추가를 안내하는 알림이 온다.

정기 알림에는 소리를 지정하지 않는다. 시간 민감 알림으로 요청하지만 실제 표시와 진동은 iPhone 알림 설정 및 집중 모드에 따른다. 알림을 탭하면 짧은 확인 화면이 열린다. 일본어를 보고 뜻을 확인한 뒤 **알았어요**를 누르면 성공 횟수가 하나 오른다. **다시 볼게요**는 횟수를 유지한다. 성공 3회가 되면 해당 단어는 학습완료단어목록으로 이동한다. **이 단어 그만 보기**는 완료로 처리하지 않고 알림 대상에서 제외한다. 한 번 진입하면 서로 다른 단어 두 개를 확인한 뒤 완료 화면이 나온다. 중앙의 넓은 **터치하여 학습 화면으로** 영역을 터치하면 학습 탭으로 이동하고, 터치하지 않아도 30초 후 같은 동작을 한다. 남은 단어가 있으면 **조금 더 학습하기**를 선택할 수 있다.

iOS 26의 AlarmKit에는 보장되는 무음 옵션이 없으므로 시스템 알람 기능은 사용하지 않는다. 이전 버전에서 예약한 1-3-3 시스템 알람은 앱 활성화 때 취소하고, 저장된 알림 시간·간격은 소리 없는 정기 알림에 그대로 적용한다. 전환 시 알림 권한이 없다면 iOS 권한을 요청한다. 앱 자체 테스트 알림은 제공하지 않는다.

단축어 앱의 voca-ios 동작 **1-3-3 학습 시작**은 학습 화면을 직접 연다. 단축어의 자동화 실행은 사용자가 단축어 앱에서 설정해야 한다. 알림이 다른 앱 화면을 강제로 전환하거나, iPhone이 잠긴 상태에서 사용자 대신 잠금을 해제할 수는 없다.

## 단축어 자동화 연결

iOS 27의 단축어에는 **알림 수신** 자동화 조건이 있다. 앱을 voca-ios로, 제목 필터를 `1-3-3`으로 정하고 동작을 **1-3-3 학습 시작**으로 선택하면 된다. iOS 26의 단축어 알람 조건은 시계 앱 알람을 대상으로 하며, 1-3-3 일반 알림이나 과거 AlarmKit 알람의 발생을 조건으로 사용할 수 없다. 자동화로 앱을 열더라도 잠금 상태에서는 잠금 해제가 필요하다.

서버에서 보내는 SMS/iMessage는 단축어의 **메시지 수신** 조건으로 연결할 수 있으나, 발송 서비스 운영·비용이 필요하고 앱을 잠금 해제 없이 표시하지는 못한다. 일반 원격 푸시만으로는 iOS 26에서 단축어의 메시지 수신 조건이 생기지 않는다. 따라서 iOS 27에서는 로컬 알림→알림 수신 자동화를 먼저 사용하는 편이 간단하다.
