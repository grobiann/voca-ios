# 짧은 단어 확인 알림 제안 (미구현)

목표는 일하는 흐름을 크게 끊지 않으면서 일본어를 자주 접하는 것이다. iOS는 다른 앱을 사용 중일 때 voca-ios 화면을 강제로 열 수 없으므로, 로컬 알림을 띄우고 사용자가 탭하면 1~2장의 짧은 확인 화면으로 들어가는 흐름을 권장한다. 사용자가 voca-ios를 보고 있을 때에는 작은 인앱 배너를 보여 줄 수 있다.

## 제안 기본값

- 기본은 꺼짐. 계정 → 짧은 단어 확인에서 사용자가 켤 때 알림 권한 요청.
- 알림 간격 90분. 선택지 30 / 60 / 90 / 120 / 180분.
- 활동 시간 평일 09:00~18:00, 하루 최대 4회. 시작·종료 시각, 요일, 하루 최대 횟수 조정 가능.
- 한 번에 1장, 선택하면 2장. 확인 화면은 일본어를 보여 주고 탭하면 한국어를 보여 준다. `알았어요` / `다시 볼게요` 한 번으로 끝낸다. 2장 모드에서는 두 장 후 자동으로 닫히며 언제든 `지금은 넘기기` 가능.
- 알림 본문에는 단어 1개만 표시하고 뜻은 숨긴다. 잠금화면 노출을 원하지 않으면 `단어 숨기기` 설정을 둘 수 있다.
- 이미 학습 중인 스택의 카드를 우선 고르되 같은 단어를 연속 알림에 사용하지 않는다. 알림에서 응답한 경우 기존 학습 기록과 같은 규칙으로 처리하고, 단순히 알림을 무시한 경우 기록을 바꾸지 않는다.
- 조용한 시간, 일일 최대 횟수, 1시간/오늘 일시 중지 단추를 제공한다. 일정에 맞춰 알림을 예약하고 설정 변경 시 기존 예약을 교체한다.

## 구현할 때 확인할 사항

알림은 iOS가 표시·전달하며 집중 모드와 사용자의 알림 설정 영향을 받는다. 예약 시각의 정확한 화면 전환을 보장할 수 없다. 권한은 사용자가 기능을 켤 때 요청한다. 알림 탭으로 열 때는 이미 선택된 단어를 바로 보여 주고, 앱 안에서 1~2장의 확인을 마친 뒤 원래 화면으로 돌아간다. 반복 알림에 서로 다른 단어를 싣고 활동 시간/일일 상한을 지키려면 향후 발생분을 개별 예약하고 앱을 다시 열 때 보충하는 방식을 사용한다.

결정할 선택지: 기본 간격(제안 90분), 활동 시간(제안 평일 09:00~18:00), 하루 최대 횟수(제안 4회), 회당 카드 수(제안 1장).
