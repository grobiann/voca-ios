# 좋아요 한 번 탭 전송 설계

기존 라이브러리 등록 Google Form과 응답 시트는 사용하지 않는다. 별도의 비공개 Google Sheet `CardVoca 좋아요 집계 (비공개)`의 `좋아요` 탭에 날짜별 횟수만 남긴다. 시트 ID는 저장소에 넣지 않고 Apps Script의 스크립트 속성 `LIKES_SHEET_ID`로 설정한다.

`scripts/cardvoca_like.gs`를 별도 Google Apps Script 웹 앱으로 배포하면 앱이 `POST {"type":"like","client_id":"앱이 만든 UUID"}`를 한 번 전송한다. 스크립트는 `좋아요` 탭의 날짜별 횟수와 `앱별 좋아요` 탭의 ID별 누적 횟수를 증가시킨다. 메일은 보내지 않는다. 로그인 정보, 이메일, 실제 기기 ID, 학습 데이터는 수집하지 않는다. 앱 전용 ID는 `UserDefaults`에 보관한다.

배포 설정은 **실행 사용자: 나**, **액세스 권한: 모든 사용자**가 필요하다. 사용자의 Google 로그인이나 권한 승인은 필요하지 않다. 공개 URL은 누구나 요청할 수 있어 완전한 1인 1회 보장은 불가능하다. 서버는 하루 100,000회에서 기록을 멈춘다. 비정상 사용으로 집계가 부풀려질 수 있으므로 이 수치를 중요한 의사결정에 쓰지 않는다.

웹 앱을 2026-11-08에 배포했다. 앱의 ‘개발자’에서 버튼을 누르면 즉시 하트 애니메이션을 보여주고, 전송은 뒤에서 진행한다. 성공·실패·대기 문구를 표시하지 않는다. 실제 iPhone에서 동작을 추가 검증한다. TestFlight 업로드는 사용자가 별도로 지시할 때만 한다.
