# 공개 라이브러리 등록 요청

- 앱의 **Google Sheets 목록 → 공개 등록 요청**은 선택한 시트 링크를 미리 입력한 [Google Form](https://docs.google.com/forms/d/e/1FAIpQLScBdgPR8fvde4wA2Lnmz8KMz48-KzmLAW0TR6n8Fva9Co20Cg/viewform)으로 엽니다. 현재 Form은 Google 계정당 한 번만 응답할 수 있습니다.
- Form 응답은 [CardVoca 공개 라이브러리 목록](https://docs.google.com/spreadsheets/d/1ffae20f-FFBJCvyIiu49kj1UKz3YuMMQYFYKiJmEbVw/edit)의 **설문지 응답 시트1**에 자동으로 저장됩니다. 응답 탭의 오른쪽에 검토 상태 열을 추가해 처리해도 됩니다.
- 운영자는 제출된 링크가 읽기 공개인지와 단어장 형식을 검토한 뒤 **공개 목록** 탭에 직접 추가합니다. 앱은 공개 목록을 다음 실행 시 다시 읽습니다.
- 공개 목록 파일은 링크가 있는 사용자에게 **보기** 권한만 둡니다. Form 응답 권한으로도 제출은 가능합니다.
