## 설명

내 속도에 맞춰 일본어 단어를 익히세요.

• 일본어와 한국어를 확인하는 카드 학습
• 모르는 단어를 다시 만나고 익힌 단어 대신 새 단어를 채우는 학습 풀
• 따로 담은 단어를 단계별로 확인하는 반복 학습
• 한자 대신 읽기를 보여주는 가나 모드
• Google Sheets의 덱별 단어장 가져오기
• 운영자가 검수한 공개 라이브러리 둘러보기
• 직접 설정하는 일본어 검색 사이트
• 기기에 보관하는 학습 기록과 단어 오류 제보

학습 기록은 이 기기에 저장됩니다. 앱 자체의 로그인, 기기 간 동기화, 알림은 없습니다. Google Sheets 가져오기와 외부 검색에는 인터넷 연결이 필요합니다. 공개 라이브러리 등록을 신청할 때는 별도의 Google Form을 사용하며 Google 계정 로그인이 필요합니다.

기본 JLPT 단어장은 공식 전체 출제 목록이 아닌 공개 자료입니다. 한국어 뜻은 자동번역 후 일부만 교정되어 있으므로 의심스러운 항목은 다른 사전과 대조해 주세요.

## App Review 메모

앱 자체 로그인과 결제는 없습니다. 첫 실행 후 학습 탭의 기본 단어로 오프라인 카드 학습을 확인할 수 있습니다. 카드를 탭해 정답을 표시하고 좌우 스와이프로 응답합니다. 반복 학습에 담은 단어는 별도 학습 흐름에서 일본어→한국어로 확인할 수 있습니다.

라이브러리의 ‘둘러보기’는 운영자가 검수한 공개 라이브러리 목록을 읽습니다. ‘Google Sheets 가져오기’는 링크 읽기 공개된 파일만 사용합니다. 설정의 ‘공개 등록 요청’은 Google Form을 외부 브라우저에서 열며, 제출된 내용은 운영자가 수동 검토합니다. 외부 검색도 사용자가 선택한 사이트를 브라우저로 엽니다. 오류 제보는 기기에 저장되며 사용자가 공유 대상을 선택하기 전에는 전송되지 않습니다.

심사 중 네트워크가 끊겨도 기본 단어 학습은 가능합니다. 앱은 알림·시스템 알람·카메라·마이크 권한을 요청하지 않습니다.
