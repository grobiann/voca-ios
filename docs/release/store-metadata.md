## 설명

내 속도에 맞춰 일본어 단어를 익히세요.

• 일본어와 한국어를 확인하는 카드 학습
• 모르는 단어를 다시 만나고 익힌 단어 대신 새 단어를 채우는 학습 풀
• 따로 담은 단어를 단계별로 확인하는 반복 학습
• 한자 대신 읽기를 보여주는 가나 모드
• Google Sheets의 덱별 단어장 가져오기
• 운영자가 검수한 공개 라이브러리 둘러보기
• 직접 설정하는 일본어 검색 사이트
• 기기에 보관하는 학습 기록과 단어 오류 제보

학습 기록은 이 기기에 저장됩니다. 앱 자체의 로그인, 기기 간 동기화, 알림은 없습니다. Google Sheets 가져오기와 외부 검색에는 인터넷 연결이 필요합니다. 공개 라이브러리 등록을 신청할 때는 별도의 Google Form을 사용하며 Google 계정 로그인이 필요합니다.

기본 JLPT 단어장은 공식 전체 출제 목록이 아닌 공개 자료입니다. 한국어 뜻은 자동번역 후 일부만 교정되어 있으므로 의심스러운 항목은 다른 사전과 대조해 주세요.
